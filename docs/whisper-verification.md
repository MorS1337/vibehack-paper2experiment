## Физическая русская диктовка

Пользователь произнёс фразу:

> Проверить границу Хёффдинга для независимых случайных величин и сравнить
> вероятность отклонения с теоретической оценкой.

В поле задачи добавлено:

> Проверить границу Февдинга для независимых случайных величин и сравнить
> вероятность отклонения стеретической оценкой. Проверить границу Февдинга
> для независимых случайных величин и сравнить вероятность отклонения
> стеретической оценкой,

Наблюдались два повтора в результате. Качество `base` недостаточно для точного
распознавания научных имён: «Хёффдинга» и сочетание «с теоретической» искажены.
Автоматическое исправление и выдуманная расшифровка не применялись.
Поле остаётся редактируемым; исправление текста в UI проверено.
После диктовки в изолированной истории **0 экспериментов**.
Аудио пользователя не добавлено в репозиторий; временный WAV удаляется интеграцией.

## Проверки поведения

- Реальный микрофон: start → AudioWorklet → stop/flush → PCM16 mono 16 kHz →
  локальная расшифровка → добавление текста.
- Отмена записи в production UI: реальные tracks переходят в `ended`,
  AudioContext — в `closed`, текст задачи не меняется.
- Закрытие формы при ожидающем getUserMedia: после закрытия доставлен настоящий
  поздний физический stream, все его tracks остановлены.
- Esc отменяет ожидание. Зависший getUserMedia в UI через 15 секунд показывает
  инструкцию и разблокирует форму. Эти ожидания моделировались задержкой Promise.
- macOS TCC на машине уже имел `granted`. Ветка `denied` проверена в production UI
  подменой ответа `getMediaAccessStatus`, без изменения системного разрешения.
  Новый системный диалог allow/deny и подписанный app bundle **не проверены**.
- Ограничение 60 секунд и защита от повторных start/stop проверяются автоматически.
  Сам AudioWorklet проверяется на downmix и flush последнего неполного блока.
- Проверены отмена при permission/resume/flush/transcribe, отсутствие позднего
  добавления текста и адресация отмены идентификатором запроса.
- Тестовый CLI — настоящий дочерний процесс: проверены `-l ru`, ошибки, пустой
  результат, 30-секундный timeout, cancel, shutdown, отсутствие живого PID
  и удаление временного каталога. В этих тестах ASR заменён тестовым CLI;
  физическая диктовка выше использует настоящий whisper.cpp.
- Проверены отсутствие binary/model, запрет `.en`, невалидный WAV и длина >60 с.

Автоматические проверки: `tests/voice-task.test.ts`, `tests/microphone.test.ts`,
`tests/recorder.test.ts`, `tests/whisper.test.ts`. Полный набор и smoke запускаются
на Node 24.22.1. Системный Node 23.4.0 не подходит установленному Undici 8
(отсутствует Zstd API); зависимости при этой работе не менялись.

Итог: `npm run build` — успешно; полный набор — **55 passed, 1 skipped**
(Linux-only watchdog); smoke — успешно, включая настоящий Python, независимый
пересчёт метрики, отмену, timeout и восстановление истории. `git diff --check` —
без замечаний. Ошибок renderer в UI-проверках не наблюдалось.

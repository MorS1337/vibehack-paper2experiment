# Collab: продолжить с телефона

Откройте **Collab** в заголовке desktop-приложения. Выберите Wi-Fi для той же
доверенной сети или HTTPS для подключения из другой сети. Отсканируйте QR либо
передайте ссылку на телефон. В браузере устанавливать приложение не требуется.

Для Wi-Fi используется TCP 4317 (можно изменить через `PAPER2_COLLAB_PORT`). Если ОС спрашивает о входящих соединениях,
доступ должен быть разрешён; изолированная гостевая Wi-Fi сеть может запрещать
соединения устройств. Ссылка выбирается по физическому сетевому интерфейсу.
При нескольких адресах выберите сеть, доступную телефону.

HTTPS требует cloudflared: `npm run collab:setup` скачивает официальный релиз
2026.10.3 в исключённую из Git папку `.tools/`, проверяет GitHub asset SHA-256,
распаковывает только исполняемый файл. Установки службы, автозапуска или изменения
системного PATH нет. Можно использовать свой binary через `PAPER2_CLOUDFLARED`
или штатную установку в PATH. В HTTPS-режиме сервер слушает только 127.0.0.1.

Cloudflare Quick Tunnel выдаёт временный адрес без аккаунта. Его адрес меняется
после перезапуска, SLA нет. Он не поддерживает SSE, поэтому события передаются
длинными HTTP-запросами: ответ приходит сразу при обновлении либо через 20 секунд.
Источник: [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

Телефон может импортировать статью, загружать PDF до 25 MiB, читать оригинал,
составлять research brief, вести живой чат, менять и сохранять план,
запускать/отменять работу, подтверждать Vast, смотреть результаты и скачивать
файлы до 64 MiB каждый. Для выбора папок, Python/Whisper/SSH указывается путь на
компьютере; системные desktop-диалоги с телефона не вызываются. Папка запуска
остаётся на компьютере, вместо её открытия доступны скачивания отдельных файлов.
Микрофону нужен HTTPS (либо localhost при проверке на компьютере).

Просмотр разрешает только чтение snapshot, исходного PDF, истории событий,
разговора и собранных артефактов.
Запрет изменений, включая upload и оплату Vast, проверяет сервер. Кнопки изменения
на плане/запуске/настройках отключены. Вход к Pi-провайдерам и сохранение их ключей доступны только на desktop;
браузер видит лишь публичный статус подключения.
Владелец control-ссылки получает возможности настольного приложения: ссылка
предназначена только для доверенных людей.

Ссылки содержат независимые случайные 256-битные токены в `#p2e=…`. Фрагмент не
отправляется при загрузке страницы; браузер убирает его из адресной строки и хранит
ключ только в sessionStorage вкладки. API получает ключ в Authorization, не query.
Сервер не пишет токены на диск или в журнал. QR создаётся локально, внешнего
сервиса для QR нет. Ссылки истекают через 12 часов, отключение сервера немедленно
отзывает обе. Выход на телефоне удаляет локальный ключ, но не отзывает ссылку для
остальных. Загруженные PDF сохраняются во временной папке ОС `paper2-uploads`.

Wi-Fi использует HTTP, поэтому подходит для доверенной локальной сети. HTTPS
шифрует путь до Cloudflare; Cloudflare завершает TLS и может видеть запросы,
заголовок Authorization и данные. Сквозного шифрования как в OMP relay здесь нет.
Не публикуйте control-ссылку. Хост-компьютер выполняет эксперименты с прежними
правами текущего пользователя и прежним подтверждением платной аренды.

Один Electron main передаёт HTTP RPC в уже работающий utility process. Второго
Harness/Store нет. Записывающие команды упорядочены в host, чтобы два редактора
не перезаписали одну версию плана. Отмена остаётся доступной во время операции.
Desktop и браузер получают одни события и поток обновлений разговора. После сетевого обрыва клиент повторяет
подключение с задержкой до 15 секунд и перечитывает snapshot, события и разговор; пропуск
кольцевого буфера событий тоже вызывает перечитывание. Обрыв связи не повторяет
записывающие запросы и не отменяет вычисления. При закрытии приложения сервер
останавливается и дочерний cloudflared завершается.

HTTP не имеет CORS, проверяет Origin, разрешает только известные RPC; native
`choose`, `folder`, `shutdown`, Pi login и настройка sharing с телефона недоступны.
Оригинальный PDF отдаётся отдельным авторизованным endpoint после проверки
импорта и SHA-256 в harness; системный путь в браузер не передаётся. CSP
запрещает внешние скрипты/frames. Статика ограничена каталогом renderer. Скачивание
разрешает только зарегистрированные обычные файлы внутри папки запуска и сверяет
SHA-256; обход пути и symlink запрещены.

## Происхождение

Подход, форма входа и base64url helpers адаптированы из
[can1357/oh-my-pi](https://github.com/can1357/oh-my-pi/tree/0b5c27ab24719c86a5986b95ee55f4e75bc1aaa0/packages/collab-web),
commit `0b5c27ab24719c86a5986b95ee55f4e75bc1aaa0`. Исходники:
`src/lib/link.ts`, `src/components/shell/ConnectScreen.tsx`, документация
`docs/collab.md`. [MIT license](third-party/oh-my-pi-LICENSE) сохранена.
OMP session protocol, browser tool cards и публичный relay не копировались:
наш UI и transport работают с ExperimentRun/AppAPI проекта.

## Дизайн и интеграция paper-first

Collab основан на `feat/paper-first-research-workspace` и использует её
типографику, цветовые токены и автоматическую светлую/тёмную тему. На телефоне
список экспериментов открывается в боковом меню, вкладки прокручиваются,
PDF и рабочая область показываются по очереди. Desktop сохраняет split view.
Диалог подключения, QR и страница ввода ссылки оформлены в том же стиле.
Браузер использует новые `importPaper`, `setBrief`, `conversation`, `sendMessage`
и `artifactPreview`; отдельной копии старого UI нет.
